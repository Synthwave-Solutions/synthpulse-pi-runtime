# SynthPulse Pi runtime releases

Builds the Raspberry Pi ARM64 WebUI from pinned Synthwave-Solutions/hermes-webui and hermes-agent forks. Source versions and artifact SHA-256 are recorded in each release. No customer state, tokens or account logins are shipped. Physical Pi validation is pending.

The [29 October runtime completion](builds/completion-20261029/README.md) supplies
pinned offline tiny Whisper, local personal Memory Explorer, optional customer
login branding and request-only MSP apps. Its source, hash-verified release
context, build recipe and scoped test evidence are recorded separately; the
original base-image provenance remains unchanged.
